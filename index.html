term store

"Cliente" não significa a mesma coisa em dois lugares da sua empresa.

Onimos é a camada que resolve isso antes de um agente de IA agir — um termo de negócio pode ter várias definições cadastradas, cada uma marcada com o contexto em que vale. Quando o contexto não é suficiente pra decidir, o agente pergunta em vez de adivinhar.

contexto da chamada

termo cliente
→

resolvido

o problema

Um agente que resolve termo sempre do mesmo jeito erra sem avisar.

módulo de vendas

"Cliente" é pessoa ou empresa que já efetuou pelo menos uma compra. Não inclui revendedores.

módulo de parcerias

"Cliente" é o revendedor autorizado que compra pra revender, não pra consumo final.

As duas definições estão certas — cada uma no seu módulo. Um agente que aplica só uma delas em toda consulta acerta na maioria dos pedidos e erra, sem sinalizar nada, exatamente nos casos em que o significado muda.

como funciona

Quatro etapas, nessa ordem, antes de qualquer tarefa ser executada.

  1. 01

    Extração

    O texto do pedido é comparado contra os termos cadastrados no repositório. Só o que está cadastrado é reconhecido.

  2. 02

    Resolução por escopo

    Cada definição candidata é pontuada pelas chaves de contexto que batem com a chamada atual. A mais específica vence.

  3. 03

    Contexto ou pergunta

    Se uma definição vence sozinha, seu texto é anexado à tarefa. Se duas empatam, o agente pergunta em vez de escolher.

  4. 04

    Auditoria

    Toda resolução, decidida ou não, é registrada com o termo, o contexto e a versão exata da definição usada.

correção ponto-no-tempo

Nenhuma definição é sobrescrita — só fechada e substituída.

Atualizar "cliente ativo" de 90 pra 60 dias não apaga a definição antiga. Ela fica registrada com a data em que deixou de valer, então um log de auditoria de meses atrás continua fazendo sentido.

v2 · vigente "comprou nos últimos 60 dias"
v1 · fechada há 30 dias "comprou nos últimos 90 dias"

instalação

Sem dependência externa em runtime.

git clone https://github.com/<seu-usuario>/onimos.git
cd onimos
pip install -e ".[dev]"
pytest -q
from onimos import OnimoRepository, ContextGroundingAgent

repo = OnimoRepository()
repo.add_version(
    "cliente",
    "Pessoa ou empresa que já efetuou pelo menos uma compra.",
    scope={"modulo": "vendas"},
)

agent = ContextGroundingAgent(repo)
result = agent.ground("liste os clientes", {"modulo": "vendas"})
print(result.grounded_context)
